# 秋招实习岗位聚合

把分散在各个招聘网站和公司官网上的实习岗位，每天自动汇总到一个网页上，
不用每天分别去打开十几个网站。**面向传媒 / 影视 / 内容 / AI 相关方向。**

## 它是怎么工作的

```
每天早上 9 点左右
    ↓
GitHub 免费借你一台电脑，自动运行抓取脚本（你的电脑不用开机）
    ↓
脚本去各个网站抓岗位，整理成统一格式存成 JSON 文件
    ↓
和昨天的结果对比，把新出现的岗位标上 NEW
    ↓
网页读取这些文件，展示成可搜索、可筛选的列表
```

## 数据来源

| 来源 | 说明 |
|---|---|
| 实习僧 | 实习垂直网站，量最大 |
| 网易招聘 | 网易传媒 / 网易云音乐 / 网易游戏等子品牌的实习岗 |
| 腾讯招聘 | 只取「校招应届生 + 校招实习生」 |
| 快手校招 | 2027 应届生 + 2027 实习生两个批次 |
| Moka 平台 | **40 多家公司的官网校招**，见下方说明 |

关于 Moka：很多中厂不自己开发招聘系统，而是共用「Moka」这个第三方平台搭
招聘官网。所以接入这一个平台，就等于同时接入了月之暗面、阶跃星辰、知乎、
鹰角网络、SHEIN、搜狐、恺英网络等几十家公司的官网校招页面。

## 网页上的功能

- **搜索**：职位名称、公司、城市、标签都能搜
- **筛选**：按城市、公司、档位筛选，可以只看新职位 / 只看官网校招
- **四个档位**（按优先级从高到低，用颜色区分）：
  1. 🟡 秋招可转正 —— 金色
  2. 🔵 大厂实习 —— 深蓝
  3. 🟢 中厂实习 —— 青色
  4. ⚪ 普通实习 —— 灰白
- **NEW 标记**：今天新抓到的岗位
- **官网校招标记**：紫色标签，表示直接来自公司自己的校招官网

## 想改东西的话

### 加一家公司的官网校招

打开 `scraper/moka.py`，在 `COMPANIES` 列表里加一行：

```python
{"name": "公司名字", "org": "公司代号"},
```

公司代号怎么找：打开这家公司的 Moka 校招页面，看网址里
`campus-recruitment/` 后面那一段。比如
`app.mokahr.com/campus-recruitment/moonshot/148507`，代号就是 `moonshot`。
站点编号不用管，脚本会自己找。

### 改搜索关键词

打开 `scraper/common.py`，改 `MEDIA_KEYWORDS`（传媒方向）
或 `AI_KEYWORDS`（AI 方向）。

### 改「大厂 / 中厂」的划分

打开 `docs/app.js`，改 `TOP_COMPANIES`（大厂）
或 `MID_COMPANIES`（中厂）这两个名单。

### 改每天抓取的时间

打开 `.github/workflows/daily.yml`，改 `cron` 那一行。
注意里面写的是世界标准时间，比北京时间**晚 8 小时**
（`23 1 * * *` = 北京时间早上 9 点 23 分）。

改的时候尽量别选整点（比如 `9:00`），GitHub 在每个整点排队的定时任务
最多，容易被延迟，错开几分钟（比如 9:23、14:07 这种）更容易准时跑。

## 在自己电脑上跑一次

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python run_all.py
```

## 几点说明

- **抓取频率**：每天 1 次，每个请求之间等 1.5 秒，不会给对方网站造成压力。
- **「可转正」标记偏少是正常的**：绝大多数公司的招聘页面根本不写是否可转正，
  所以只在标题/描述里明确出现「转正」「留用」「提前批」，或者是
  「27届 + 实习」这种组合时才标记。宁可少标，也不误导。
- **有些公司显示 0 个岗位**：说明他们秋招还没开放，脚本已经挂着了，
  等他们放出岗位会自动抓到。
- **GitHub 的定时任务，如果仓库连续 60 天没有任何更新，会被自动暂停**。
  正常情况下每天抓到新岗位就会产生更新，不会触发。万一真被暂停了，
  去仓库的 Actions 页面点一下重新启用即可。
- 本项目仅供个人查看岗位信息使用，抓取的都是各招聘网站公开可见的岗位内容。
